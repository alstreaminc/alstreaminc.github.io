# ALStream Tech — GitHub Engineering Gateway

Public engineering portal for the company-managed [`alstreaminc` GitHub organization](https://github.com/alstreaminc). The published site is [alstreaminc.github.io](https://alstreaminc.github.io/); the official company website is [alstreamtech.com](https://alstreamtech.com/).

**Brand assets:** `assets/alstreamtech-logo.png` is a losslessly palette-optimized copy of the transparent ALStream Tech Inc logo supplied by the company owner on 28 October 2026. `assets/alstreamtech-favicon.png` is cropped from the supplied mark for small-icon display. Do not substitute unrelated brands.

All development repositories are separate, private, and not exposed by the Pages site. This website is a public entry point, not an alternative to GitHub's authenticated PR and permissions interface.

Branding changes are proposed through pull requests and require authorized review before publication.
